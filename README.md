# Nightmare Rescue — Chapter 1: The Butcher's Kitchen

An offline-capable first-person horror game prototype built with Babylon.js.

## Run locally

```bash
npm install
npm run dev
```

Build the self-contained local assets with `npm run build`, then serve `dist/` from any local static server. No CDN or network connection is used at runtime.

## Controls

- WASD: move
- Mouse: look
- Space: jump
- Left click: whack
- Escape: release the mouse
